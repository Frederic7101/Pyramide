## Raisonnement de Syno

### e-001 : « Veilleur de nuit » → le phare

**Mot 1 : rocher** (trouvé à la brique 2, mise 2) — piste : écueil + Monaco

- écueil → *récif* ✗ — Le titre évoque le phare ; « écueil » a pour synonyme direct « récif », que le phare signale.
- écueil + Monaco → *rocher* ✓ — Le titre évoque le phare. Écueil (récif refusé) puis Monaco, surnommé le Rocher : rocher.

**Mot 2 : lumière** (trouvé à la brique 1, mise 2) — piste : clarté + écrit

- clarté → *lumière* ✓ — Le titre évoque le phare, déjà suggéré par le récif. « Clarté » a pour synonyme direct lumière.

**Mot 3 : navires** (trouvé à la brique 1, mise 2) — piste : bateaux + Titanic

- bateaux → *navires* ✓ — Titre = le phare (récif, lumière). « Bateaux » en 1re brique appelle un synonyme : navires, que le phare guide.

**Mot 4 : jetée** (trouvé à la brique 1, mise 2) — piste : digue + mercredi

- digue → *jetée* ✓ — Le titre évoque le phare (récif, lumière, navires). « Digue » a pour synonyme direct « jetée », souvent au bout de laquelle se dresse un phare.

**Mot 5 : seul** (trouvé à la brique 1, mise 2) — piste : unique + frère

- unique → *seul* ✓ — Le titre et les mots récif, lumière, navires, jetée évoquent le phare. « Unique » se lit comme un synonyme : le phare est seul face à la mer.
