## Pistes à réécrire (2 / 5 ou moins)

- e-314, mot n°5 : **Carnot + physique + bains → thermodynamique** (1 / 5) — commencer par Carnot n'est pas bon, car c'est une personne alors qu'on recherche un nom commun. il faurait fallu commencer par physique puis Carnot puis bains
- e-525, mot n°3 : **méridiens + droites → parallèles** (1 / 5) — un méridien n'est pas une droite parallèle, il vaudrait mieux utiliser latitude
- e-428, mot n°3 : **locomotive + restaurant → wagon** (1 / 5) — un wagon n'a rien à voir avec la locomotive, ni le restaurant; le lien est bien meilleur avec train+voiture
- e-531, mot n°5 : **méchant + petit canard → vilain** (1 / 5) — indice en 2 mots est une violation du règlement
- e-343, mot n°1 : **vibrer + feuille → trembler** (2 / 5) — manque une incitation, car plusieurs solutions possibles : frémir, trembler, trembloter, onduler
- e-310, mot n°3 : **écriture + Flaubert → style** (2 / 5) — écriture + Flaubert me fait plus penser à littérature qu'à style. Style est beaucoup plus large que le sens du style littéraire ; il manque une incitation
- e-316, mot n°2 : **épée + bouclier → glaive** (2 / 5) — bouclier n'est pas utile, il faudrait contextualiser le type d'épée, car il en existe beaucoup. Par exemple en indiquant "centurion" qui fait référence à l'antiquité romaine où les soldats avaient des glaives.
- e-344, mot n°2 : **rétention + éléphant → mémoire** (2 / 5) — rétention fait penser au processus, donc à mémorisation, pas à mémoire; il faudrait commencer par souvenirs ou RAM
- e-312, mot n°2 : **peur + Dieu → crainte** (2 / 5) — il faudrait une incitation
- e-333, mot n°3 : **puissance + Montesquieu → pouvoir** (2 / 5) — au lieu de Montesquieu (qui fait souvent référence aux Lettres Persannes), vouloir est meilleur comme mot associé par paire avec pouvoir
- e-333, mot n°4 : **filiation + cousinage + jardin → parenté** (2 / 5) — je ne vois pas l'utilité de jardin, il fallait une incitation comme via pour par
- e-333, mot n°5 : **valeur + médaille → mérite** (2 / 5) — il fallait une incitation en plus, car avec valeur et médaille, prix était une réponse possible (prix pour valeur d'une chose et  pour récompense/médaille)
- e-322, mot n°2 : **inspiration + Rimbaud → illumination** (2 / 5) — je ne vois pas le rapport entre Rimbaud et illumination
- e-322, mot n°3 : **clair + trouble → limpide** (2 / 5) — trouble ne sert à rien, redondant avec clair qui donne déjà le sens, il fallait inciter avec chanvre
- e-525, mot n°2 : **abysses + champ → profondeur** (2 / 5) — champ n'est pas très bon, il vaudrait mieux amateur pour inciter pro
- e-401, mot n°4 : **pâtée + Whiskas → croquettes** (2 / 5) — pâtée est bien une nourriture pour chats, mais très différente en texture des croquettes qui sont dures
- np-433, mot n°4 : **île → Madagascar** (2 / 5) — beaucoup d'îles en Afrique, il vaudrait mieux commencer par la capitale
- e-539, mot n°1 : **brisants + obstacles → écueils** (2 / 5) — il faudrait une incitation, d'autant que le premier mot sonne comme un participe présent donc on recherche un verbe conjugué
- np-540, mot n°1 : **cantor + Leipzig + fugue → Bach** (2 / 5) — cantor et Leipzig ne m'ont pas aidés, la fugue oui
- e-530, mot n°2 : **rancœur + similitude → ressentiment** (2 / 5) — il manque une incitation
- e-530, mot n°4 : **inexorable + ennemi → implacable** (2 / 5) — il manque une incitation; j'ai pris ennemi pour inciter ami; puis j'ai pensé à ennemi fatal, qui collait avec inexorable
- e-530, mot n°5 : **punition + crime → châtiment** (2 / 5) — il manque une incitation; j'ai pris crime pour inciter délit, je n'ai pas pensé à l'association "crimes et châtiments"
